##Project Overview

This project explores banking transaction data to understand transaction activity, compare branch performance, and identify useful business patterns.

The workflow covers data preparation, SQL-based analysis, and interactive Power BI reporting to demonstrate practical data analytics skills.

#Business Objectives

- Analyze transaction volumes and customer activity.
- Compare performance across branches.
- Explore transaction trends over time, where available.
- Develop an interactive Power BI dashboard.
- Communicate findings in a business-friendly format.

##Analytical Workflow

**Data Preparation:Inspect raw data, identify quality issues, and transform fields.
**Data Cleaning:Handle missing values, duplicates, inconsistent formats, and invalid records appropriately.
**SQL Analysis:Use filtering, aggregations,group by,cte, and other relevant SQL techniques.4
**Dashboard Development:Present KPIs, branch comparisons, and trends using Power BI.
**Business Interpretation:Summarize verified findings and potential recommendations.

## Business Questions

- Which branches have the highest and lowest transaction volumes?
- How does transaction activity differ across branches?
- What changes in transaction activity can be observed over time?
- Which additional metrics could help stakeholders understand performance?


## data quality and missing values

- Identified missing values in selected customer attributes,
  including age,gender and transaction date

- Retained unknown values where the correct information
  could not be verified from the available data.

- Avoided guessing or inventing customer information.

- Validated key transaction fields before calculating KPIs.

- Considered missing values when interpreting analytical results.
